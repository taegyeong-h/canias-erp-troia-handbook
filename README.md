# 🏢 Canias ERP Architecture & Domain Docs

## 💡 배경 및 계기 (Background)

데이터 엔지니어로서 데이터 파이프라인을 구축하며, 원천 데이터가 발생하는 **ERP 모듈의 비즈니스 로직에 대한 깊은 이해 부족**을 절감했습니다. 

그동안 현업 담당자분들에게 단편적인 계산 산식만 요청하며 파이프라인을 만드는 요행을 바라기도 했습니다. 하지만 원천 데이터의 흐름과 비즈니스 맥락을 알지 못하면 **정확한 데이터 모델링과 BI 화면에 신뢰할 수 있는 데이터 파이프라인 구축이 불가능하다**는 것을 깨달았습니다.

현업에만 의존하는 개발자에서 벗어나, **비즈니스 도메인을 깊이 이해하고 데이터를 주도적으로 다루는 데이터 엔지니어**로 성장하기 위해 Canias ERP의 핵심 모듈과 데이터 구조를 직접 분석하고 기록합니다.
